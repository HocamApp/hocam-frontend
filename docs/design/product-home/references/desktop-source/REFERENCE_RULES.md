# Hocam Product Home — Reference Usage Rules

The materials inside the references folder are inspiration and research
materials, not a design system to install.

## Borrow from the references

- Product-home information hierarchy
- Search placement and prominence
- Section ordering
- Recommendation patterns
- Horizontal carousels
- Card information hierarchy
- Category discovery patterns
- Responsive behavior
- Loading and empty-state patterns
- Content density and vertical rhythm
- Personalized homepage logic

## Do not borrow

- Udemy colors
- Udemy fonts
- Udemy logos
- Udemy images or illustrations
- Udemy copy
- Udemy CSS variables
- Udemy Tailwind tokens
- Udemy design token JSON
- Pixel-perfect branded styling
- Marketing testimonials or marketing footer sections

## Final design requirement

The final page must look and feel like Hocam.

Use Hocam's existing:

- typography
- colors
- buttons
- cards
- border radii
- shadows
- icon system
- navbar
- container system
- responsive conventions

References may influence structure and interaction only.
