# Brand v3

The new color system for hocamozelders.com: black, pink and yellow, with soft tints, and one strong color moment per section.

| File | What it is |
|---|---|
| `BRAND.md` | The color system: palette, tokens, composition rules, color meanings, component recipes, contrast. Source of truth for color. |
| `PLAN.md` | How to ship it: Phase 0 foundation, Phase 1 homepage, Phase 2 every page, Phase 3 lock-in. Decisions for Baha at the end. |
| `STATUS.md` | Where the rollout is. Updated after every task. |
| `mockup/home.html` | The approved homepage mockup (static, light theme, demo data). |
| `mockup/components.html` | Small parts: notifications, status chips, rank badges, avatars, progress, calendar, buttons, mobile nav. |

Start a Claude Code session with:

> Read `docs/design/brand-v3/README.md`, then `BRAND.md`, `PLAN.md` and `STATUS.md`. Do the next not-started task in `STATUS.md`, following the ground rules in `PLAN.md`. Stop at the end of the task, update `STATUS.md`, and tell me what changed and what you need from me.
